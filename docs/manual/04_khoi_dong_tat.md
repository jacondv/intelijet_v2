# 4. Daily Startup & Shutdown

## Starting the software

1. Tap the **Intelijet** icon (on the Desktop or in the application menu).
2. Every tap starts a **fresh** session. If the app is already running, tapping the icon again stops it and starts over — it does **not** "resume" where you left off. Avoid tapping the icon again while a job is in progress unless you mean to restart, since unsaved progress in that job may be lost.
3. Wait for the main screen to appear — startup normally only takes a few seconds.

> The very first time the software is started after installation, it may take noticeably longer (a few minutes), because it needs to set itself up. This only happens once.

If the window does not appear after a reasonable wait, see Chapter 8 (Troubleshooting).

## Shutting down at the end of the day

1. Press the **Exit** button in the app.
2. Confirm **Yes** when asked "Are you sure you want to quit?"
3. If a scan or report was still processing when you pressed Exit, the app waits a few seconds for it to finish before closing anyway — if possible, wait until processing is finished before pressing Exit.
4. Wait for the window to close completely.

## Reporting a problem

If you need to report a problem to a technician, the system keeps a copy of the current run's log and the previous run's log under the `data/logs` folder in the installation directory — a technician can use these to help diagnose the issue.
