# 5. User Interface Overview

The main screen has three tabs:

- **Job Number** — create, choose, and manage projects and jobs.
- **Main View** — the 3D scan view and scan controls. This is where you run scans day to day.
- **Setting** — processing options and job history. Some options here are locked to admin-level users and cannot be changed by a regular operator.

## Main View controls

| Control | What it does |
|---|---|
| Job dropdown (top) | Pick a project/job. Switching to a different job asks for confirmation. |
| **Open Scanner** / **Close Scanner** | Press and hold to open/close the Housing; releasing the button stops it immediately. See Chapter 2 for the pinch hazard. |
| **Set Home** | Resets the current Housing angle to zero. Asks for confirmation first. |
| **Pre-Scan** | Runs the "before" scan. Asks for confirmation, since it overwrites any existing pre-scan already saved for this job. |
| **Post-Scan** | Runs the "after" scan. |
| **Compare** | Compares the pre-scan and post-scan. |
| **View Report** | Opens the generated PDF report for the current job. |

## Device status indicators

Four status labels show whether the Lidar, Encoder, PCAN, and PLC are connected — green means connected, red means disconnected. See Chapter 7 for what each one means and what to do when one turns red.

## Notification bar

A line near the bottom of the screen shows the latest status or warning message, color-coded by how serious it is. Tap it to open the full notification history. See Chapter 7.
